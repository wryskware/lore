# MCP Tool Surface

Consolidation is good practice, not dogma (Wrysk, round 2): the surface below is small because these operations genuinely compose, not because of a tool-count budget. Add tools when a real workflow wants one.

## v0.1 tools

- **`search`** — one unified hybrid query. Filters: project, path glob, language, vault status. Returns ranked chunks with provenance (file, span, `heading_path` for Markdown) and vault-status labels (`decided`, cited decision IDs) so the agent can see authority at a glance.
- **`expand`** — full context around a returned chunk (surrounding code / whole section / symbol span). The "now let me actually read it" step.
- **`status`** — index health: registered projects, coverage, generation, embedding endpoint state.

## Later milestones

- **`session_log`** — post a sign-off summary to the tier-2 ledger (D-0008).
- **`recall`** — search the session ledger; answers "where'd we leave off / did we do this already", pointing back to thread names.

## Deliberate exclusions

- Registration/reindex are CLI-only (`lore add`, `lore index`) — agents don't register random directories.
- No memory-write API for durable (tier 1) memories: agents write vault files; canon flows through the promotion gate (D-0006).
- No graph tools (D-0005).
